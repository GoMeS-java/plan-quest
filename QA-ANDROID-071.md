## Реализация

Код: `2d9c6ca9fa42a760fd3700b9f3e8f6022f8ce579`; исправления крайних случаев: `2c37af8e8f536c5776e3e5cdd53b229ace126978`.

- Новый переносимый JSON v2 с датой, версией приложения и SHA-256. Экспортируется весь docs, включая неизвестные поля; токен и авторизационные метаданные не экспортируются.
- Старые v1/без v и seed-объединение поддержаны. Неизвестная схема, повреждение, неверные документы и повторяющиеся JSON-ключи отклоняются до подтверждения.
- Перед полной заменой — копия текущего профиля и пауза Google; основной снимок заменяется одним setItem. Ошибки подготовки/записи сохраняют старый профиль. Возможная побочная пауза облака безопасна и намеренна.
- Ограниченный одним экземпляром checkpoint предыдущей успешной транзакции. Ошибка его записи блокирует изменение; отсутствие места не маскируется успехом.
- При повреждении исходные байты сохраняются, исправные соседние записи остаются только для чтения. Доступен исходный файл и явное восстановление.
- Экспорт ждёт игровую очередь и сообщает о несохранённом действии; из режима только для чтения можно скачать уже сохранённые данные.
- Настройки эффектов входят в cfg/effects. Миграция старого fxset не удаляет ключ и не повторяется при существующем документе. В TEST используется только тестовый ключ.
- Вес/финансовая форма не очищается при ошибке записи; цель тела не получает ложного успешного сообщения. Выплата комиссии и подписных атомарна и защищена от повторного начисления.
- Данные/копии доступны из настроек, панель прокручивается и закрывается «Назад» без изменения экрана Цитадели.
- Дублирующиеся/сломаные/неполные строки Sheets останавливают синхронизацию до отправки. Контракт path/json/u сохранён.

Подробная карта источников истины, блокировок и ограничений: DATA-SAFETY-071.md.

## Ручная браузерная проверка и границы

В работающем изолированном пакете проверены открытие панели из настроек, Back, запись синтетического веса, сохранение после перезапуска и герой в комнате. Синтетические записи не входят в публикуемые файлы.

Эмуляция Chromium не заменяет физический Android: нужны выбор/сохранение файла через Android, установленная PWA, системная «Назад» и длительная офлайн-сессия. Реальный Google не включался. localStorage и внутренние копии не переживут удаление данных сайта или утрату устройства; необходимы внешние скачанные копии. Sheets не гарантирует распределённую атомарность двух одновременно работающих устройств; при конфликте нужна сверка. Старые браузеры без Web Locks не имеют межвкладочной блокировки.
