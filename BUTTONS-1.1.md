# Кнопки и основные пути «Вкач 1.1»

Изменения 3 ноября 2026 года по указанию владельца. Профиль — основной центр управления героем и персональными настройками.

| Действие | Основной путь теперь | Что изменилось |
|---|---|---|
| Достижения и витрина | Профиль → Достижения | Убрана отдельная кнопка-трофей из группы «Система» общего меню. Три места витрины остаются в профиле. |
| Настройки и данные | Профиль → Настройки и данные | Убрана отдельная шестерёнка из общего меню. Окно открывается поверх профиля; закрытие возвращает в профиль. |
| Обучение | Профиль → Обучение | Для не завершивших «Пробуждение» — продолжение общего прохода; для завершивших — короткий курс по новому профилю, достижениям и оформлению. В настройках доступны запуск и повтор. |
| Полученные оформления | Профиль → нужная карточка категории | Четыре категории сохранены как прямые входы в разные виды оформления. Карточка сразу открывает нужную категорию. |
| Фон и рамка | Профиль → Фон и рамка | Прежнее название «Цитадель и убежище» уточнено. Здесь общий фон и рамка профиля. |
| Одежда и титул | Профиль → Гардероб / Выбрать звание | Сохранены самостоятельные операции: надеть предмет, выбрать или снять титул. Наградные вещи отмечены в гардеробе после получения. |
| Финансы | Разделы → Финансы → Траты / Деньги / Колесо | Убраны Авито, его счета, ввод сумм, отдельная вкладка и кнопки. Убран повторный вход «Траты» из общего меню. Старые записи в копиях сохранены; личный бюджет не изменён. |
| Обзор замка | Разделы → Управление замком → Обзор Цитадели → Обзор | Совпадающие «Обзор» и «Прогулка» сведены к одному действию. |
| Вход в комнату | Нажать на доступную комнату; дополнительные действия — в панели выбранной комнаты | Убран повторный общий вход «Интерьер» из левой панели. Панель выбранной комнаты сохраняет контекст и доступность с клавиатуры. |
| Обустройство и улучшение | Выбранная комната → раздел «Обустройство» | Убран повторный общий вход «Строительство» из левой панели. Доступ к улучшению в контексте выбранной комнаты сохранён. Кнопка покупки показывает реальную стоимость. |
| Украшение комнаты | Внутри выбранной комнаты → Оформление комнаты | Штандарт, фонарь и другие полученные возможности относятся к этой комнате. Общий фон Цитадели выбирается в профиле. |
| Синхронизация и обновление приложения | Общий статус приложения; данные — также через профиль | Глобальный статус и штатное обновление остаются доступными как раньше. Восстановление копий и правила синхронизации сохранены. |

Оставшиеся контекстные входы в комнату и улучшение полезны при работе с выбранной комнатой и с клавиатуры. Дальнейшее уплотнение этих панелей следует проверять на физическом Android вместе с возвратом назад, фокусом и экранной клавиатурой.
