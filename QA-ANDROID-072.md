# Вкач 0.72 — повседневные финансы и прогресс

1 ноября 2026. citadel-development-20261030, PR #1. main, production и реальные записи не изменялись. Только синтетические профили и mock Google.

## Изменения в приложении

- Операция редактируется в существующей форме: сумма, дата, тип, счёт, категория и описание. Сохраняются ID, исходный timestamp, counted/pending и неизвестные поля; второй операции нет. При конкурентном изменении запись не перезаписывается молча: ввод остаётся, требуется открыть актуальную запись.
- Денежный ввод принимает точку/запятую и пробелы-разделители; некорректные, отрицательные и суммы с более чем двумя знаками отклоняются. Формулы доходов, расходов, долгов, переводов и RPG не изменялись.
- Удаление записи требует подтверждения и проверяет актуальность документа. Сохраняется защита checkpoint 0.71. В истории доступна подгрузка по 40 записей, включая старые даты; новый аккаунт без начального баланса видит журнал, а неизвестные остатки остаются явно отмечены.
- Финансовые формы, Авито, копилка, списки и создаваемые задания защищены от повторной отправки во время записи; при ошибке ввод сохраняется. Успех показывается после durable-записи.
- Списки финансов и Авито не перестраиваются при несвязанных изменениях; ввод/фокус динамических форм сохраняется при необходимой перерисовке. Изменённая удалённо сумма Авито не принимается поверх незавершённого редактирования без проверки.
- Спонтанное задание можно переименовать; повторный быстрый add не создаёт дубликат. Название и дата существующей записи, отметка и прочие поля сохраняются при изменении одного поля.
- Ежедневная запись транзакционно меняет только выбранные поля, изменённые индексы q и ключи ex. Отметка одного задания не стирает соседнюю отметку, шаги, калории или неизвестные поля.
- Разные типы упражнений не стирают друг друга; быстрый повтор соблюдает прежний интервал. Счётчики испытания применяют дельту к актуальной записи, а не сохраняют старый объект целиком.
- Недельная отметка и независимые поля прогресса обновляются частично. Условия, награды и баланс не менялись.
- Переход через полночь обновляет пустую дату операции, сохраняя дату незавершённого ввода. Смена даты устройства не удаляет историю.
- Неизменённый весовой график переиспользует SVG. На синтетическом профиле 500 операций/300 измерений пять полных refresh заняли около 75–78 мс в локальном headless Chromium. Это не измерение физического Android и не CI-порог.

## Проверки

Полный локальный `npm run test:all` прошёл: **75 игровых групп + 5 групп изоляции + экономика**, без ошибок JavaScript. После него два дополнительных сценария частичного обновления прогресса/недели и смены даты/повторного выполнения прошли отдельно; они включены в финальный набор из 77 групп.

Выполнены `python build.py`, `python build.py --test`. npm run test:all включает npm test, npm run test:economy, npm run test:isolation. Финальный CI версии 0.72 выполняет весь набор повторно; фактические ссылки и результаты приведены в пользовательском отчёте.

Новые проверки:
1. Создание → изменение → удаление одной операции на 320/360/390/430 CSS px и 844×390. Десятичные суммы, выбранная дата, длинное описание, повторное нажатие, отмена удаления, балансы и перезапуск.
2. Ошибка хранилища сохраняет форму. Устаревшее редактирование не затирает свежую запись; неизвестные поля остаются.
3. Черновики списков и Авито переживают изменения веса/дня; сумма и общий итог обновляются, повторное добавление не дублируется.
4. Две вкладки одновременно меняют разные отметки, шаги/калории и счётчики: все изменения и неизвестные поля сохранены.
5. Быстрые повторы упражнений не обходят прежний интервал, разные типы и отмена сохраняются после перезапуска.
6. Добавление/переименование задания и ошибка записи без потери ввода.
7. Большая история, подгрузка 40→80, точные финансовые итоги и стабильность DOM без лишнего рендера.
8. Новый профиль без заданных начальных сумм показывает операции и не выдаёт неизвестные балансы за известные.
9. Неизменённый файл tests/fixtures/backup-071-synthetic.json с v2/SHA-256 восстанавливает финансы, задания, настройки и общую фигуру; перезапуск сохраняет результат.
10. Независимые поля прогресса и недельная отметка сохраняют соседние данные между вкладками.
11. Повторное выполнение, переход через полночь и обратная смена даты не дублируют ресурсы и не удаляют историю/финансовый ввод.

TEST-изоляция дополнена настоящей офлайн-записью финансов/шагов и вторым офлайн-перезапуском до восстановления копии. Production sentinel и Google отключены. Прежняя регрессия проверяет живого героя, гардероб, анимации, 10 комнат/5 ярусов, покупки, ресурсы, Колесо, камеру, резервные копии/конфликты и обновления PWA.

Git data API принял все blob/tree/commit, но update_ref возвращал ошибку missing. Применён безопасный contents API, только к заданной ветке и с проверкой blob SHA. Итоговое дерево 96e33283d3361ca2a8ecd1c6b7547f5a09d36ffc точно совпало с локально проверенным набором; force-push не применялся. Промежуточные коммиты могут иметь устаревший CI: итоговые запуски важнее их состояния.

Эмуляция Chromium не заменяет физический Android: нужны клавиатура одной рукой, реальные системные Back/файловый менеджер, установленная PWA и длительная сессия. Реальные Google/Авито API не включались. Внешние резервные копии всё ещё необходимы: удаление данных браузера удаляет внутренние копии. Межустройственная атомарность Sheets и Web Locks в старых браузерах остаются ограничениями 0.71.
