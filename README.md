# План Квест: офлайн-приложение

Что это: игра «План» как установленное приложение (PWA). Данные хранятся на телефоне
и синхронизируются с файлом `plan-data.json` на Google Диске. Код хостится отдельно.

## Структура
- `src/game.html`: сама игра (тот же код, что был в артефакте)
- `src/localdb.js`: локальная база + синхронизация с Диском + плашка в углу
- `src/config.js`: сюда вставляется Google Client ID
- `src/sw.template.js`, `src/manifest.json`: офлайн-кэш и установка
- `build.py`: собирает папку `docs/` (её и публикуют на хостинге)
- `seed.json`: стартовые данные (НЕ класть в репозиторий, только на телефон/Диск)

Сборка: `python3 build.py` (нужен Pillow для иконок).

## Формат файла данных (plan-data.json на Диске)
    { "v": 1, "docs": { "<коллекция>/<id>": { "d": { ...поля... } | null, "u": <мс> } } }
- `d: null`: запись удалена
- `u`: время изменения в мс. При слиянии побеждает больший `u`.
- Правя файл вручную (через Диск), ставь `u` = текущее время в мс, иначе правку перебьёт телефон.
- Коллекции: tx, items, avito, jar, weights, buys, days, per, weeks, goals, wardrobe, cfg (opening, outfit, cart).

## Формат seed.json (первый импорт)
    { "v": 1, "seed": { "<коллекция>/<id>": { ...поля... } } }
Импортируется кнопкой «Импорт из файла» в меню плашки (угол экрана).

## Публикация
1. Приватный репозиторий на GitHub с содержимым этой папки (без seed.json).
2. Cloudflare Pages: подключить репозиторий, команда сборки `python3 build.py`
   (или залить готовую `docs/`), каталог публикации `docs`.
3. Google Cloud: проект, экран согласия (внешний, опубликовать в продакшн), OAuth client ID типа Web,
   Authorized JavaScript origins = адрес сайта из Cloudflare, scope `drive.file`.
4. Client ID вставить в `src/config.js`, пересобрать, запушить.
5. На телефоне открыть адрес в Chrome → «Установить приложение» → меню плашки → «Войти через Google»
   → «Импорт из файла» (seed.json) → «Синхронизировать».
