План Квест: политика конфиденциальности

Дата обновления: 22 октября 2026.

Что это за приложение

«План Квест» — личное приложение для учёта задач и финансов. Оно работает в браузере или установленным на телефон и не имеет собственного сервера.

Какие данные и где хранятся

Все данные хранятся в памяти устройства пользователя и, если пользователь вошёл через Google, в одном файле plan-data.json в его личном Google Диске. Приложение запрашивает только право drive.file: оно видит и меняет только файл, который само создало, и не имеет доступа к остальным файлам Диска.

Что мы не делаем

Мы не собираем, не передаём и не продаём данные третьим лицам, не используем аналитику и рекламу. Разработчик приложения не получает доступ к вашим данным.

Как удалить данные

Удалите файл plan-data.json из своего Google Диска и очистите данные сайта в браузере. Доступ приложения можно отозвать на странице myaccount.google.com/permissions.

Контакты

Вопросы можно задать через репозиторий проекта: github.com/GoMeS-java/plan-quest.

Privacy policy (English)

Plan Quest is a personal task and finance tracker with no server of its own. Data is stored on the user's device and, after Google sign-in, in a single file (plan-data.json) in the user's own Google Drive. The app requests only the drive.file scope, so it can access only the file it created. We do not collect, share or sell data, and use no analytics or ads. To delete your data, remove the file from your Drive, clear site data in the browser, and revoke access at myaccount.google.com/permissions.
