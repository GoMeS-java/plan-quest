# Вкач 1.0 · Личная приёмка

Реализация «Пробуждения» и протокол обновления описаны в
[QA-RELEASE-100.md](QA-RELEASE-100.md). Базовая версия — 0.90.

Кандидат релиза требует успешной полной автоматической регрессии и CI на
исполняемом коммите, совпадения Android TEST с чистой изолированной сборкой,
а затем проверки владельцем на физическом Android.

Аппаратные проверки: системный Back, реальная экранная клавиатура, поворот,
выгрузка процесса, повторный запуск, офлайн и сверка сохранённого прогресса.
Резервную копию скачать до обновления; сайт и PWA данные не очищать.
Обучение существующего игрока запускается добровольно из настроек.

Полная аппаратная приёмка не заявляется по результатам Chromium или публикации.
Основная ветка и объединение PR #1 требуют отдельного разрешения владельца.
