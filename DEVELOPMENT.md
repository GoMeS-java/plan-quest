# Разработка «Вкач»

Исходники приложения находятся в `src/`, проверенная обычная сборка — в `docs/`.
`python build.py --test` создаёт изолированную сборку `android-test/`.
Не редактируйте сгенерированные файлы вручную.

Локальная документная база доступна через `window.PlanDB`. Она предоставляет
`doc`, `collection` и синхронный callback `runTransaction`; уведомления подписок
доставляются асинхронно. Успех записи подтверждается только завершившимся Promise.
Ключи `plan.*`, схема v1 и формат переносимой резервной копии не зависят от
имени JavaScript-интерфейса. Изменять их при рефакторинге нельзя.

Перед записью проверяйте актуальную вершину рабочей ветки. Работа ведётся в
`citadel-development-20261030`; main, merge PR, force-push и production запрещены.
Тесты используют только синтетические данные. Не раскрывайте скрытые достижения.
Не подключайте реальные Sheets и Авито в тестовой сборке.

Проверки: `python build.py`, `python build.py --test`, `npm run test:all`.
Для локального Chromium можно задать `CHROMIUM_EXECUTABLE_PATH`.
Результат локальных проверок не заменяет GitHub Actions того же коммита.
Эмуляция Chromium не заменяет ручную приёмку на физическом Android.

## Аудит инструментов разработки · 01.11.2026

Проверены все 222 отслеживаемых файла, скрытые конфигурации, единственный
workflow, зависимости и доступные локальные неотслеживаемые файлы проекта.
Внешних AI SDK, модельных API, агентских hooks и отдельных агентских инструкций
не обнаружено. Удалены старый глобальный адаптер хранилища, устаревший метатег
и привязанные к внешнему сервису пользовательские тексты. Общих инструкций,
требующих переноса из удаляемого агентского файла, не было.

История коммитов и авторство сохранены. Исторический эталон в browser-тестах
загружается из Git; только его bootstrap базы адаптируется к текущему `PlanDB`.
Тесты обновления PWA используют неизменённые исторические комплекты файлов.

Список секретов и внешних webhook в настройках GitHub недоступен через текущий
коннектор. Наличие остаточных секретов не подтверждено; секреты не изменялись.
Владелец может проверить Settings → Secrets and variables → Actions и Environments,
сначала установить отсутствие потребителей, затем отозвать неиспользуемый ключ у
провайдера и удалить соответствующий секрет. Не помещайте значения ключей в отчёт.
