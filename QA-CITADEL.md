# Проверка интегрированной «Цитадели Спящего»

Дата: 30 октября 2026. Ветка: `citadel-development-20261030`.
Базовая версия для сравнения игровой логики: `c65a44e`.

## Результат

Сборка, существующие CI-контракты и 11 групп браузерных регрессий прошли.
В проверенных сценариях ошибок выполнения JavaScript не обнаружено.
Проверки используют искусственные сохранения; личные данные игрока и настоящий Google-аккаунт не затрагиваются.

## Что исправлено

- Переход к сегодняшним заданиям и испытанию сбрасывает режим «Вчера».
- Действие с экипировкой открывает существующую «Оболочку».
- Изменение размера окна, поворот экрана и разворачивание замка сохраняют открытый интерьер и результат осмотра.
- Положение персонажа учитывает границу замка; восстановление выбранной комнаты работает после перезагрузки.
- Выбор комнаты и оформление сохраняются в `cfg/citadel` через общую базу и синхронизацию. Прежние локальные настройки переносятся при первом запуске, исходные ключи остаются резервной копией. Уже имеющаяся общая запись имеет приоритет.
- Оформление обновляется при получении данных синхронизации. Закрытые комнаты имеют доступное описание состояния.
- При переходе через полночь задания, сводки и таймер обновляются без перезагрузки приложения.
- Устранена потеря изменений при быстрых отметках ежедневных задач и повторных нажатиях счётчиков испытаний до получения подписки базы.
- Увеличены области нажатия и читаемость текста Цитадели; добавлен перенос длинных строк на узких экранах.
- Убрана устаревшая фиксированная оценка разработки «40%»; пересобран `docs/`, включая ранее отсутствовавшие результаты сборки и новый кэш PWA.

Расчёт экономики, каталоги достижений, условия открытия, награды, штрафы и схемы существующих игровых коллекций не менялись. Цитадель читает существующие показатели; отдельного баланса, персонажа или копии квестов не создаёт.

## Запуск проверок

Нужны Python с Pillow, Node.js 22+ и история Git, содержащая базовый коммит.

```sh
python build.py
npm ci
npx playwright install --with-deps chromium
npm test
```

Для уже установленного совместимого Chromium можно указать `CHROMIUM_EXECUTABLE_PATH`.
Локально использован Chromium 153 через Playwright; CI устанавливает штатный Chromium Playwright.
Workflow запускается при изменениях этой ветки, подходящих pull request и вручную.

## Оставшиеся ограничения

- Проверка мобильного интерфейса выполнена в Chromium с сенсорной эмуляцией. Физический Android, установка на домашний экран, системный возврат, экранная клавиатура и iOS/Safari отдельно не проверялись.
- Google OAuth и Sheets проверены с тестовыми ответами API. Реальный вход и синхронизация с личной таблицей не выполнялись.
- Строительство с расходованием валюты, расширение этажей и полноценные распорядки жителей ещё не интегрированы в основную игру. Демонстрационный прототип сохранён отдельно. Новые траты и источники наград не вводились, чтобы сохранить существующую экономику.
- Общие настройки Цитадели используют прежнюю модель синхронизации: побеждает более новая запись документа. Одновременное редактирование оформления на двух офлайн-устройствах не объединяется по отдельным комнатам.
- `test_app.py` — прежний ручной тест с внешним `seed.json`; он не запускался. Новый набор не требует личного seed и не изменяет исходники во время проверки.

Скрытые каталоги, условия и награды в этот отчёт и журналы нового набора тестов не включаются.
